《不做牛马宣言》

倡导并践行”不做牛马，纯过日子“的生活方式，是这本书的核心理念。

这本书不是指南，不是党章，不是信仰。它是一粒种子，一簇火苗，希望能够唤醒每个人心中最真实的声音，按照自己喜欢的方式过这一生。

它不是想要推翻什么，只是想告诉你，那原本属于你的生活，从此刻开始，应该慢慢还给你自己。
